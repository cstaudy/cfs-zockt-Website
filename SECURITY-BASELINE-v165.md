# Security Baseline v165

v165 ändert keine Authentifizierungs-, OAuth-, Provider-, Stream-Key-, Session-, Device-Link-, Bridge- oder Credential-Grenzen.

Die Login-Seite zeigt weniger technischen Text im ersten Blick, entfernt aber keine Sicherheitsfunktionen: MFA, Recovery-Codes, Passkeys, E-Mail-Verifikation, CSRF-/Origin-Schutz sowie die rechtlichen Registrierungsbestätigungen bleiben bestehen.

Die Launcher-Downloadseite verwendet weiterhin ausschließlich den öffentlichen read-only Release-Katalog. Download-Aktionen bleiben deaktiviert, solange kein veröffentlichter Stable-Release vorhanden ist. Lokale Streaming-Zugangsdaten bleiben lokal verschlüsselt.

Es wurden keine Tracker, Drittanbieter-Skripte oder neue externe Assets ergänzt.
