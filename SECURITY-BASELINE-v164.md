# Security Baseline v164

v164 ändert keine Credential-, OAuth-, Stream-Key-, Session-, Bridge- oder Provider-Grenzen.

Der Pass betrifft ausschließlich die öffentliche Informationsarchitektur und responsive Darstellung. Sicherheitsrelevante öffentliche Links (`security.txt`, Status, Legal) bleiben über bestehende technische/sekundäre Navigation erreichbar. Rechtseiten behalten die v163-Regeln `noindex,follow,noarchive,nosnippet` und bleiben im Footer verlinkt.

Der transparente Logo-Asset-Pfad aus v161 bleibt unverändert. Keine neuen Drittanbieter-Skripte, Tracker oder externen Assets wurden ergänzt.
