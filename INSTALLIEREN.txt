cfs_zockt v140 – kumulatives Updatepaket
=========================================

WAS DIESES PAKET IST
--------------------
Dieses ZIP ist KEIN vollständiger Projekt-Export.
Es enthält alle bisher neu angelegten oder geänderten Update-Dateien in ihrer
jeweils neuesten Fassung und baut auf deinem bestehenden cfs_zockt Projekt auf.

V140 SCHWERPUNKT
----------------
- Widget Studio Code-Audit abgeschlossen.
- Launcher-Kern Code-Audit abgeschlossen.
- Launcher auf 0.47.17 synchronisiert.
- fehlende Launcher-Runtime-Bausteine ergänzt/gefestigt.
- Widget Runtime / OBS Browser-Source-Pfad geprüft.
- Stream-Studio-/Scene-Studio-Testverträge auf aktuellen Protokollstand gebracht.
- kompletter lokaler Stream-Studio-Aggregatcheck läuft durch.
- Creator-Suite Release Gate auf v140 aktualisiert.

INSTALLATION
------------
1. ZIP entpacken.
2. Den INHALT des Ordners in dein bestehendes Projekt kopieren.
3. Vorhandene Dateien ersetzen.
4. Keine Secrets aus Render in Dateien eintragen.
5. Erst committen/deployen, wenn wir den gemeinsamen Release-Stand freigeben.

WICHTIG
-------
- Keine neuen Render-Secrets für v140 notwendig.
- Für den späteren echten Launcher-Release müssen die bestehenden Release-Werte
  auf 0.47.17 zeigen:
  CFS_LAUNCHER_BUILD_TARGET_VERSION=0.47.17
  CFS_RELEASE_EVIDENCE_VERSION=0.47.17
- CFS_PLAYSTATION_NPSSO bleibt ausschließlich als Secret in Render.
- Stream-/Provider-Credentials bleiben Launcher-lokal; nicht in GitHub oder Render kopieren.
