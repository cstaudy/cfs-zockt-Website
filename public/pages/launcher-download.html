WARUM DER LAUNCHER?

LOKALE FUNKTIONEN BLEIBEN LOKAL.

Die Website ist das Control Plane. Der Launcher übernimmt Funktionen, die direkt auf deinem Windows-PC laufen müssen.

01Stream Studio

Lokale Capture-, Audio-, Recording- und Streaming-Engine für den Creator-PC.

02OBS Integration

OBS WebSocket verbinden, Szenen lesen und veröffentlichte Widgets als Browser Source einsetzen.

03Sichere lokale Credentials

Stream-Zugangsdaten werden lokal verschlüsselt gespeichert und nicht als normale Website-Daten behandelt.

04Bridge & Recovery

Geräte-Link, Heartbeat, Reconnect und Diagnose verbinden Desktop und Creator Account kontrolliert.

INSTALLATION

IN DREI SCHRITTEN STARTKLAR.

1
Setup herunterladen

Nutze den offiziellen Setup-Download oben. Portable ist für Tests oder einen Start ohne Installation gedacht.

2
Launcher installieren & öffnen

Der Release wird auf GitHub gebaut. Öffentliche Tag-Releases müssen den Windows-Signaturcheck bestehen.

3
Creator Account verbinden

Im Launcher einen Device-Link erzeugen und anschließend mit deinem Creator Account bestätigen.

RELEASE-SICHERHEIT

Kein versteckter Web-Download.

Die Download-Seite verweist ausschließlich auf veröffentlichte Release-Artefakte. Ist kein Stable-Setup veröffentlicht, bleibt der Download deaktiviert.

  • Setup und Portable getrennt
  • SHA-256-Datei im Release
  • Release-Manifest im Build
  • Kein Stream-Key im Downloadprozess
