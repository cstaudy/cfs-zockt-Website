# Security Baseline v162

v162 verändert keine Credential-, OAuth-, Stream-Key- oder Bridge-Grenzen.

Zusätzliche Privacy-Grenze für die öffentliche Hauptseite:

- keine private Kontakt-E-Mail
- keine Postanschrift
- keine Telefonnummer
- keine Geburtsangabe
- kein persönlicher Klarname als Marketing-/Profiltext
- öffentliche Social-/Creator-Handles bleiben zulässig
- Anbieter-/Kontaktinformationen bleiben auf den rechtlichen Seiten begrenzt
- JSON-LD bleibt über expliziten CSP-Hash freigegeben

Siehe `PUBLIC-PRIVACY-AUDIT-v162.md`.
